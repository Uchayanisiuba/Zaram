# Zaram System Architecture (5-Layer OS)

## Layer 1: KERNEL
Registry, Scheduler, Dependency Injection, Event Bus, Execution Engine.
*Core owns orchestration. Nothing bypasses Core.*

## Layer 2: INTELLIGENCE
Conversation, Attention, Memory, Knowledge, Learning, Identity, World, Executive, Emotion, Behaviour, Speech, Vision, Workspace, Automation, Tool Runtimes.
*Independent runtimes communicating via contracts and events.*

## Layer 3: PROJECTION
Presence Runtime.
*Translates AI state into abstract FrameState. Knows no renderer.*

## Layer 4: EMBODIMENT
Living Orb, Avatar, MetaHuman, Robot, VR, AR.
*Consumes FrameState. Knows no cognition.*

## Layer 5: PLATFORM
Electron, Web, Android, iOS, Unreal Engine.
