# Documents — proposals, invoices, spreadsheets, decks

## Asking for a document

Talk first, then ask for the document. *Write that up as a proposal.* *Turn this into meeting notes.* *Draft an invoice for the three days.* Zaram writes it from what was discussed and from what it remembers, and the file appears as a card in the conversation. It also lands in **Work**.

## What it can make

- **Prose documents**: proposal, statement of work, report, memo, brief, meeting notes, plan, letter, cover letter, email, summary, press release, article. Each kind has the sections a reader expects — a proposal has Summary, What you need, What we propose, Scope, Timeline, Fees, Assumptions, Next steps.
- **Invoice** — line items, quantities, rates and a total Zaram computes rather than takes from the model. It asks for anything missing.
- **CV**.
- **Spreadsheet** — *make me a spreadsheet of those numbers.*
- **Slide deck** — *make a five-slide deck from this.*
- **Chart** — from figures Zaram has as data. It cannot chart prose; it says so and offers a document instead.

## Formats

Every document is made as a web page first, so the preview is exactly what you get, then saved as **PDF**, **Word (.docx)**, **Excel (.xlsx)** or **PowerPoint (.pptx)**. Say the format if you care — *as a Word file* — or set the default in Settings.

## Where a fact comes from

Claims in a document carry their source, and the sources are listed at the end if you ask for them. If Zaram cannot find what you are referring to — *write that up* with nothing to write up — it stops and asks rather than inventing a client. Where a single fact is missing, it writes *[to confirm]* in its place.

## Letterhead

Under **Settings → Letterhead**, set your name, address and logo once. Every document carries them.

## A document as a shape

Attach a document you already have and ask for another like it. Zaram follows its structure.

## Editing

Zaram makes documents; you edit them in Word, Excel or whatever you already use. Open the file from the card or from Work.

## Removing a document

In **Work**, select a document and remove it. It goes to a folder inside Zaram's output folder rather than being deleted outright, so it can be put back. Emptying that folder is up to you.

## Which model writes

A long, structured document is the one job worth waiting for your strongest model on. Under **Settings → Models → Advanced**, the *Writing documents* row lets you choose one; with a cloud key connected, Zaram's pairing offer fills it for you.
