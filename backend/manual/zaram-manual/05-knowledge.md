# Knowledge — the documents Zaram reads

## Adding a folder

Open **Knowledge** and choose **Add a folder**. Zaram reads every document it can — PDF, Word, Excel, plain text, Markdown — and remembers what they say, with the file name attached to every fact. Reading happens on your machine. Nothing is uploaded anywhere.

A folder stays watched: if you change a file in it, Zaram reads the new version; if you remove a file, Zaram notes that it has gone.

## Adding a single file, or text

Drop a file onto Knowledge, use **Upload**, or paste text. Zaram keeps its own copy of uploaded files in its own folder, so the original can move without breaking anything.

## Scanned documents

A PDF that is a scan — a photograph of paper — has no text inside it. Zaram says so, next to the file, and offers the **Reading scans** pack, which adds text recognition. Until then the file is listed and not read.

## What Zaram cannot read

Each file shows whether it was read. One that was not says why, in a sentence: the format, a password, a scan. Nothing is skipped silently.

## Domains

A **domain** is a named group of sources with a one-line description — *Investing*, *The Harbour Lane job*, *Course reading*. Domains are for finding: a question is answered from the domain that fits it, and the reply says which — *answered from your Investing domain*. A source can be in several domains at once. There is one memory underneath; domains never split it.

To make one: **Knowledge → Domains → New**, name it, describe it in one line, and choose which sources belong.

## The Zaram domain

One domain is built in: **Zaram**, which holds this manual. Ask *how do I export my memory?* or *what leaves my computer?* and the answer comes from these pages, with a citation, whatever model is answering. It cannot be deleted, and it is refreshed when Zaram updates.

## Privacy per source

Each source has a policy: whether facts from it may be sent to a cloud model at all. Set it under the source. The default for a new source follows your routing choice.

## Removing a source

Remove a source and its facts go with it; answers stop citing it. Removing a domain removes only the grouping — the sources and facts stay.
