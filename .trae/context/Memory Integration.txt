## 1. Registration
Commands are registered at runtime via the `ICommandRegistry` interface. 

```typescript
interface CommandManifest {
  id: string; // e.g., 'zaram.surface.open.knowledge'
  title: string;
  description: string;
  category: 'navigation' | 'action' | 'ai' | 'system';
  icon: string;
  permissions: string[]; // e.g., ['filesystem:read']
  handler: (payload?: any) => Promise<void> | void;
  shortcuts?: string[]; // e.g., ['mod+k', 'mod+shift+k']
}
