## The Living Orb

**What it is:** Visual representation of AI runtime state  
**Position:** Bottom-center (docked)  
**States:**
- **Idle:** Indigo/violet gradient, slow breathing
- **Listening:** Emerald gradient, ripple animation
- **Thinking:** Blue/cyan gradient, swirling particles
- **Executing:** Amber/orange gradient, pulsing
- **Error:** Red gradient, shaking

**Interactions:**
- Click → Command Palette
- Double-click → Voice input
- Right-click → System menu
- Hover → Radial menu (8 slots)

## Workspaces

8 workspace types (users switch via dock):
1. **Learn** - Research, Knowledge Engine
2. **Build** - Development, Code Studio
3. **Create** - Image/video generation
4. **Automate** - Workflow automation
5. **Communicate** - Chat, email, meetings
6. **Develop** - Full IDE
7. **Manage** - Tasks, calendar, projects
8. **Explore** - Memory graph visualization

## Design Philosophy

**Inspired by:**
- Apple Vision Pro (spatial)
- Linear (minimal, fast)
- Raycast (keyboard-first)
- Arc Browser (workspace-centric)
- Nothing OS (calm, elegant)

**Key Attributes:**
- Calm over clutter
- Spatial over linear
- Confident over apologetic
- Premium over cheap
- Human over mechanical

**Visual Style:**
- Dark mode only (default)
- Glassmorphism (sparingly)
- Subtle gradients
- Physics-based animations
- High contrast, readable typography

## Memory Graph Schema

**Node Types:**
- DOCUMENT, CODE_FILE, CONVERSATION, TASK, EVENT, ENTITY, PROJECT, WORKSPACE

**Edge Types:**
- AUTHORED_BY, REFERENCES, DEPENDS_ON, SUPERSEDES, RELATES_TO, CONTAINS, MENTIONS

**Every node has:**
- UUID, type, engine origin, payload, embeddings, metadata (timestamps, workspace, access control)
