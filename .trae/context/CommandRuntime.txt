## 1. Context Packet Schema
The fundamental unit of Zaram's memory is the `ContextPacket`.

```typescript
interface ContextPacket {
  id: string;
  type: 'code_snippet' | 'document_summary' | 'user_intent' | 'system_state';
  source: string; // e.g., 'BuildSurface', 'KnowledgeSurface'
  content: string | Record<string, any>; // The actual data
  vector?: number[]; // Optional embedding for semantic search
  metadata: {
    confidence: number; // 0.0 - 1.0
    tags: string[];
  };
  timestamp: number;
  ttl: number; // Time-to-live in milliseconds (0 = permanent)
}
