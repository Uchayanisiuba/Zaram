# Zaram Project Rules

Zaram is a Local-First AI Productivity Operating System.

Never design individual applications.

Always think in terms of Workspaces.

The application shell consists of:

- Top Navigation
- Left Context Panel
- Center Workspace
- Right Runtime Panel
- Bottom Adaptive Dock

The Living Orb is a companion.

It is NOT the application.

The workspace is always the hero.

UI Principles

- Calm
- Elegant
- Premium
- Minimal
- Spatial
- Glassmorphism
- Apple Vision Pro inspiration
- Cursor quality interactions
- Motion communicates state
- No clutter
- Maximum readability

Architecture

Always preserve:

Electron
IPC
Runtime
Voice
Memory
Knowledge
Automation
Backend contracts

Never modify backend interfaces unless explicitly requested.

Always build reusable React components.

Use:

React 19
TypeScript
Tailwind v4
Framer Motion
Zustand

Never hardcode colors.

Always consume design tokens.

Every component must be production quality.

When uncertain, prioritize consistency over novelty.
