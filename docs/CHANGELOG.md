## [1.0.0-RC2] - Knowledge Universe Integration
### Added
- **Knowledge Universe Specification:** Full semantic mapping of spatial objects (Galaxies, Solar Systems, Stars, Planets, Comets, etc.) to data types (Projects, Agents, Memories, Knowledge, Tasks, etc.).
- **Orb-Centric Intelligence:** Documented that the Living Orb is always the central intelligence. The Universe responds. Never the reverse.
- **Interaction Modes:** Documented instant switching between Orb Mode, Avatar Mode, and Universe Mode.
- **Expanded Knowledge Runtime Providers:** Added support for Vector DBs, Graph DBs, Code Repositories, Databases, APIs, Bookmarks, and future providers.
- **Expanded Embodiment SDK:** Added support for MetaHuman, RPM, VRM, ARKit, Robots, Drones, Floating AI, VTubers, and Knowledge Universe themes.
- **Expanded Marketplace Categories:** Added Galaxy Themes, Memory Packs, Workspace Templates, and Enterprise Compliance Packs.

### Changed
- **Presence Runtime:** Updated to document how `FrameState` projects to all three embodiments (Living Orb, Avatar, Knowledge Universe).
- **Rendering & Embodiment Layer:** Renamed from "Dual Embodiment" to "Triple Embodiment System."
- **ADR-016:** Expanded Knowledge Runtime Provider Interface to include all data source categories.
- **ADR-013:** Expanded Embodiment SDK to support all embodiment types and added Knowledge Universe themes.
- **ADR-003:** Expanded Marketplace into Developer, Creator, and Enterprise stores with detailed categories.

### Status
- **Architecture:** RC2 (Knowledge Universe Integration Complete).
