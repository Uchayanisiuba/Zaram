# Zaram Alpha 1.0 - Platform Overview

## 1. Vision
Zaram is a Local-First Personal AI Operating System. It is an intelligent companion that lives with the user, remembers what matters, reasons across time, and takes multiple forms.

## 2. Business Model
### Zaram Core (One-Time Purchase)
- **Price:** $49 (Lifetime)
- **Includes:** Unlimited local AI, orchestration, agents, memory, and updates.
- **Philosophy:** No subscriptions. You own your software.

### The Marketplace
A built-in ecosystem for third-party developers: Skills, Characters, Voice Packs, Knowledge Packs, Workspace Packs, Automation Packs, Embodiments, and Themes.

### Cloud Credits (Optional)
Pay-as-you-go for cloud models (GPT, Claude, Gemini, Deep Research). Local users never lose functionality.

## 3. Core Philosophy
The user talks to **one intelligence**. Zaram decides everything else. Technology disappears into the background.
