ZARAM AI Operating System - Figma Design Prompt
Project Overview
Design a complete, modular UI design system for ZARAM - an AI-powered Desktop Operating System built with Electron + React. The interface should embody a calm, minimal, spatial, and futuristic aesthetic inspired by Apple Vision Pro, OpenAI's design language, Nothing OS, Arc Browser, and Iron Man's JARVIS.
🎨 Design Philosophy & Core Principles
Primary Concept: The interface must feel ALIVE - users should interact with an intelligent digital lifeform, not traditional software. The Living Orb is the emotional center; everything else orbits around it.
Key Attributes:
Calm & Minimal: No clutter, no neon cyberpunk, no visual noise
Premium & AAA Quality: Every pixel should feel intentional and polished
Organic & Cinematic: Soft shadows, deep blacks, subtle gradients, dynamic depth
Spatial & Futuristic: Glassmorphism, layered depth, fluid animations
Invisible Interface: UI recedes when not needed; content is primary

🔧 Figma-Specific Implementation Notes
Component Properties
Use Figma's component properties for:
Boolean: Show/hide elements (icons, badges, dividers)
Instance Swap: Icon variants, avatar images
Text: Labels, titles, dynamic content
Variant: States (default, hover, active, disabled)
Auto-Layout Best Practices
All containers use auto-layout
Use "Fill container" for flexible widths
Use "Hug contents" for buttons, badges
Set min/max widths for responsiveness
Use padding consistently from spacing scale
Constraints & Responsive Behavior
Pin elements to edges appropriately
Use "Scale" for icons that should grow with container
Use "Left & Right" for full-width elements
Test at 2560px, 1920px, and 1366px widths
Interactive Components
Create interactive variants for:
Button hover/active states
Toggle on/off
Window controls (minimize, maximize, close)
Dock item magnification
Tab switching
Prototyping Interactions
Use "Smart Animate" for smooth transitions
Set appropriate easing (spring for playful, ease-out for UI)
Use delays for staggered animations
Create overlay animations for modals, menus
Design Tokens Export
Name layers and styles for easy developer handoff:
Color styles: zaram/bg-primary, zaram/accent-cyan
Text styles: zaram/display-xl, zaram/body-md
Effect styles: zaram/glass, zaram/glow-cyan
Use consistent naming: component/variant/state
📦 Export & Handoff Specifications

Icons: SVG format, 24px base, optimize for web
Images: WebP format, multiple resolutions (@1x, @2x, @3x)
Logos: SVG + PNG transparent background

CSS class names (e.g., .glass-panel, .living-orb)

Before marking as complete, ensure:
All components have hover, active, and disabled states
Typography scale is consistent throughout
Color contrast meets WCAG AA standards (4.5:1 minimum)
All interactive elements have focus states
Animations are smooth (60fps) and not jarring
Glassmorphism effects work on both light and dark backgrounds
Components are responsive and test at all breakpoints
Naming convention is consistent (kebab-case for layers)
All variants are documented
Prototype flows are complete and functional
Design tokens are exported as styles
Component properties are properly configured
No unused layers or hidden elements
File is organized and easy to navigate

Modular: Any component can be used independently
Consistent: Visual language is unified across all screens
Scalable: Easy to add new components or variants
Accessible: Meets accessibility standards
Developer-Friendly: Clear handoff with tokens and specs
