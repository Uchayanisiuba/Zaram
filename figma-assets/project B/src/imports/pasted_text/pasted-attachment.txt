Zaram UI Prompt for Figma AI
Project Overview

Design the complete user interface for Zaram, a Local-First AI Operating System.

Zaram is not a chatbot, not a desktop clone, and not a browser.

It is a living operating system centered around an intelligent entity that exists at the heart of the experience.

The interface should feel like:

Apple Vision Pro
Arc Browser
Linear
Notion
Raycast
ChatGPT
Unreal Engine editor

combined into one coherent operating system.

The overall feeling should be:

Calm.

Intelligent.

Premium.

Spatial.

Minimal.

Alive.

The user should feel like they are working with an intelligent partner rather than controlling software.

Design Philosophy

Design around these principles:

Living Intelligence First
Local-first
Spatial computing
Calm technology
Context over windows
Motion with purpose
Glassmorphism
Infinite workspace
AI always present but never intrusive

Avoid:

Windows 11 look
macOS clone
Generic dashboard
Cyberpunk UI
Gamer aesthetic
Flat enterprise software

Landing Experience

When no workspace is open:

The Orb occupies the center.

Around the Orb are six primary destinations arranged in an elegant orbital layout.

              Build

 Memory               Knowledge

        Living Orb

 Plugins             Canvas

             Settings

These nodes should orbit slowly around the orb.

When hovered:

enlarge slightly
glow
subtle particle attraction

When clicked:

they animate toward the center and become the active workspace.

Workspace

When a workspace opens:

The Orb gracefully shrinks.

It moves to the Runtime Panel.

The workspace expands into the center.

The transition should feel organic.

Never abrupt.
